# TravelT

**TravelT** is a Windows Desktop application designed to blend travel planning with social discovery and gamification. Built with C# and WPF, Travelt allows users to build itineraries, share their journeys, and unlock achievements along the way.

---

## Core Features

*   **Create Travel Plans:** Build and organize custom travel itineraries by country and destination.
*   **Social Discovery:** Share your travel experiences through posts and discover new destinations on the global feed.
*   **Achievement System:** Earn badges and unlock achievements (e.g., *"First Post"*, *"Bio Added"*) as you interact with the platform and complete your travels.
*   **User Profiles:** Customize your personal travel profile to showcase your plans and unlocked achievements.
*   **Admin Toolbox:** Built-in administrative tools to moderate content and manage the platform.

---

## Tech Stack

*   **Language:** C#
*   **Framework:** .NET / WPF (Windows Presentation Foundation)
*   **UI/UX:** XAML
*   **Database:** MySQL (run locally via XAMPP)
